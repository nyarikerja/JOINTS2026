02

Abu vulkanik

Dari tinggi kolom abu ke laju erupsi massa

Tinggi kolom pada buletin VONA dikonversi menjadi laju erupsi massa dengan relasi empiris Mastin dkk. (2009). Massa tersebut kemudian dibagi ke ribuan paket partikel yang diadveksi oleh medan angin.

Skenario hipotetis untuk ilustrasi. Nilai dihitung dari persamaan, bukan dari pengamatan.

03

Asap kebakaran lahan

Emisi PM2.5 diestimasi dari daya radiasi api

Setiap titik panas VIIRS dari NASA FIRMS membawa nilai Fire Radiative Power (FRP). Nilai itu dikonversi menjadi biomassa terbakar dengan koefisien Wooster dkk. (2005), lalu dikalikan faktor 2,34 untuk lahan gambut tropis sebelum asapnya dilepas ke model angin.

Contoh ilustratif untuk lanskap gambut Riau, Sumatera Selatan, Kalimantan, dan Papua.

05

Metode

Empat tahap dari data terbuka ke rekomendasi

Seluruh tahapan berjalan otomatis, sehingga pengguna di daerah tidak perlu mengolah data mentah sendiri.

  1. Akuisisi data

    Data PVMBG, NASA FIRMS, Open-Meteo, WorldPop, dan OpenStreetMap diperbarui otomatis tanpa input manual.

  2. Simulasi ensemble

    Aplikasi menjalankan 15 hingga 51 anggota integrasi Lagrangian RK2 dengan perturbasi angin. Demo di halaman ini memakai 24 anggota.

  3. Analisis paparan

    Zona 90%, 50%, dan 5% ditumpangkan pada grid penduduk 100 m serta lokasi sekolah dan fasilitas kesehatan.

  4. Rekomendasi tindakan

    Triase sekolah, rute ke rumah sakit di luar sebaran abu, anjuran respirator N95/KN95, dan prioritas pemadaman klaster titik api.

Hujan lebat mempercepat pencucian abu dari atmosfer, tetapi endapan di lereng dapat memicu lahar hujan. Untuk kondisi ini sistem menerbitkan peringatan sekunder.

  • OtomatisSumber dan parameter diambil dari data resmi terbaru.
  • SkenarioUbah tinggi kolom, arah angin, atau curah hujan. Keluaran diberi label hipotetis.
  • Titik bebasJalankan simulasi dari koordinat mana pun di wilayah Indonesia.
